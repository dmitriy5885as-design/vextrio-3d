# VEXTRIO 3D — фирменный стиль

Публичное имя: **VEXTRIO 3D**. Прежнее имя FORMA используется только в исторических материалах и технических идентификаторах совместимости.

Слоган: «Придай идее форму» / Shape your ideas. Продукт остаётся бесплатным, без регистрации и платных ограничений.

Знак: геометрическая буква V из синих и бирюзовых граней на графитовом скруглённом фоне. Исходник — `public/vextrio.svg`, векторный ресурс без внешних шрифтов или изображений. `public/forma.svg` содержит тот же новый знак и остаётся совместимым адресом для старых ссылок. Старый знак F не используется приложением.

Палитра интерфейса: Graphite `#161C28`, Blue `#3478F6`, Mint `#4DD5C0`, Cloud `#F2F5FA`. Геометрия знака добавляет cyan `#23B4FF` и turquoise `#00BBCB`. Тёмная тема остаётся основной; светлая тема сохраняет функциональность и доступность текста. Типографика: Inter, Manrope, Segoe UI с системным fallback.

Генерация всех нативных иконок из одного SVG:

```powershell
node node_modules/@tauri-apps/cli/tauri.js icon public/vextrio.svg --output apps/desktop/src-tauri/icons
```

Не переименовывать `@forma/*`, `studio.forma.editor`, `forma-editor`, `.v3d` или `format: "forma"` ради визуального единообразия. Имя проекта, пользовательские объекты, расширения и содержимое старых файлов не являются текстом интерфейса и не переводятся в новый бренд.
