# Локальные вырезы в сценах с независимыми деталями

Основа: main `4c29ae7b`, Alpha.16. Работа в `codex/geometry-reliability`.
Версия приложения не повышается; Alpha.17 / PR #27 этой работой не объединяется.

## Исправленные отказы

Существующая ниша Alpha.16 в стене 4 × 3 × 0,2 м не могла углубиться ещё
на 50 мм, если в том же GeometryModel находились 650 независимых удалённых
треугольных деталей. `boundaryCut` передавал весь документ в `splitSegments`
и получал отказ лимита 512 исходных отрезков. Проверка контактов всех граней
этой сцены отдельно исчерпывала бюджет 200000 пар ещё до проверки расстояния.
Оба отказа воспроизведены тестами до изменения реализации.

Теперь planar arrangement выреза получает только редактируемое тело, с прежним
мировым допуском и резервом ID всей сцены. После обработки восстанавливаются
неизменённые независимые сущности, затем валидируется полный кандидат.
Контакты новой границы с рёбрами других тел отклоняются явно, включая свободные
линии. Между телами не создаётся неявное сваривание.

Контроль граней сортирует мировые AABB вдоль самой протяжённой оси и отбрасывает
далёкие пары. Бюджет узкой проверки расходуется только на перекрывающиеся AABB.
Точные проверки контактов и предел 200000 потенциальных пар сохранены.

## Проверяемое поведение

- Ниша 50 мм углубляется до 100 мм: объём материала 2,32 → 2,24 м³.
- Следующие 100 мм завершают сквозной проём: объём 2,08 м³.
- Все таблицы независимых деталей сохраняют прежние значения и ID.
- Общая история возвращает точные состояния через Undo/Redo; .v3d проходит
  сериализацию и повторное открытие без изменения геометрии.
- Пересечение новой поверхности с другим телом отклоняется, не меняя документ,
  ревизию или существующую ветку Redo. Контакт новой границы с отдельной линией
  также отклоняется без изменения источника.
- Новый браузерный тест открывает подготовленный .v3d, выбирает заднюю грань
  настоящим кликом, вводит P=-50mm, скачивает результат и проверяет Undo/Redo.
  Для самого редактирования прямых вызовов ядра из браузера нет.

## Проверки и пределы

Полный Vitest: 540/540, 41 файл. Production build / TypeScript и check:deps
успешны. Предупреждение Vite о chunk >500 kB сохраняется.

Production E2E в установленном Edge: 15/15, один worker, без retries и
увеличения timeout: alpha15, boundary-pocket, pushpull и large-contact-scene.
Полный набор остальных E2E в этой работе не запускался. Первый dev-прогон
дал 11 успешных сценариев, один timeout и два пропуска после перезагрузки
страницы во время изменения тестовых файлов; окончательный прогон выполнен
на стабильном production preview порта 5187.

Эта работа убирает зависимость локального выреза от количества удалённых тел.
Лимит splitSegments внутри самого редактируемого тела не повышается;
произвольные булевы пересечения, большие плотные CAD-модели и новые типы
проёмов не заявляются. Это проверка корректности конкретного сценария,
не обещание производительности на любых моделях. Windows installer и offline
приёмка здесь не выполняются. Изменения не опубликованы на GitHub или Pages.
