## Утверждённые решения

1. Сохранить React/Three.js/Tauri и работающие адаптеры, добавить независимую топологию постепенно; не заменять приложение целиком.
2. Источником истины сделать документ с вершинами, рёбрами, ориентированными обходами, гранями, оболочками, телами и определениями групп/компонентов. Three.js хранит только отображение.
3. Для 0.2 поддержать прямолинейные рёбра и плоские грани. Образовывать грани через плоское разбиение с пересечениями, а не через перечень произвольных циклов графа.
4. Автоматически обрабатывать пересечения отрезков в активном контексте и разбиение компланарных граней. Общие пересечения неплоских/некомпланарных поверхностей и объёмные boolean — отдельные последующие функции; их отсутствие явно показывать.
5. Ввести v2 формата с сохранением примитивов v1 без потери и без автоматического фасетирования сфер/цилиндров; преобразование в редактируемую геометрию — явная операция.
6. Транзакции содержат прямой и обратный delta, результаты Worker применяются только к ожидаемой ревизии. Предпросмотр и камера не засоряют историю редактирования.
7. Первый этап после утверждения — S1: безопасная валидация команд, воспроизводимые v1 fixtures и проверяемые границы модулей. Рисование и новые файлы v2 появятся на следующих этапах, не в S1.

Утверждение этих решений разрешает S1. Дальнейшие этапы выполняются по зависимостям плана с проверкой критериев; существенное изменение области или геометрических правил требует новой фиксации решения.
