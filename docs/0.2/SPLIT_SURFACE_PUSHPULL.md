# Push/Pull через разделённую противоположную поверхность

> Включено в общий выпуск **0.2.0-alpha.18**. Ниже сохранён отчёт об отдельном этапе разработки; актуальный статус и ограничения выпуска — в [README](../../README.md).

Ветка `codex/pushpull-split-surfaces`, поверх Alpha.17 и исправления PR #28.
Это расширение возможностей, ещё не опубликованная версия сайта.

## Пользовательское изменение

Противоположная плоская стенка может состоять из нескольких смежных граней.
Контур окна/двери теперь можно выдавить через разделяющие рёбра, не стирая их
заранее. Кнопка «До противоположной грани» распознаёт общую глубину такой стенки.
Частичная ниша у пола также может быть последовательно закончена в проём.
Снаружи проёма сохраняются разделение, ID и материалы отдельных участков.
Грань, целиком попавшая в вырез, удаляется; Undo возвращает точную топологию.

Пример: стена 4 × 3 × 0,2 м, сзади разделитель на x=1,5 м. Спереди окно
1 × 1 м пересекает этот разделитель. P=-200mm создаёт настоящую замкнутую
оболочку с проёмом; объём материала меняется с 2,4 до 2,2 м³.

## Реализация

Для определения глубины временно строится внешний контур связной копланарной
области. Внутренние разделители исключаются только из запроса покрытия;
исходные грани, материалы и документ этим запросом не меняются. Покрытие
проверяет внешний контур и все отверстия; пустота не считается материалом.

Подтверждённый сквозной вырез использует прежний локальный boundaryCut:
каждая противоположная грань подрезается отдельно через planar arrangement,
создаются канонические откосы, а весь кандидат проверяется и принимается одной
обратимой командой. Mesh не является источником геометрических решений.
Формат .v3d, Windows identifier и зависимости не меняются.

## Проверки и пределы

Добавлены проверки обеих сторон стены, последовательной ниши, сетки граней,
полного удаления внутренних ячеек, разных материалов, повёрнутой группы
с неравномерным масштабом, превышения глубины и отверстия внутри области.
Новый UI E2E строит стену, рисует разделитель сзади, строит окно спереди,
использует настоящую кнопку глубины, сохраняет файл и проверяет Undo/Redo
и повторное открытие. Итоговые результаты прогонов фиксируются при приёмке.

Локально: полный unit/integration прогон 557/557 до добавления отдельной
проверки отверстия; окончательный новый набор 8/8. Production build,
TypeScript и check:deps успешны. Прежние 11 UI-сценариев ниш, Push/Pull
и привязки глубины прошли; новый UI-сценарий отдельно прошёл за 10,5 с.
Его первый запуск остановился из-за exact-name локатора: доступное имя
кнопки включает рассчитанную глубину. Локатор исправлен, timeout не увеличен.
Полный E2E этой ветки и её Web/Windows CI локальными результатами не заменяются.

Пока поддержаны связные копланарные участки одной противоположной поверхности,
до 64 граней в запросе покрытия и с прежним бюджетом 512 отрезков локального
splitter. Наклонная/криволинейная противоположная поверхность, объединение
разных тел и общие булевы операции не добавлены. Полный выпуск и ручная
Windows/offline-приёмка выполняются отдельно.
