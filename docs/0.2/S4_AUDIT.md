## Обнаруженные блокирующие разрывы

| Проблема на входе | Исправление S4 | Проверка |
| --- | --- | --- |
| Production документ, команды и файлы знают только v1 objects | Дискриминируемый Document v1/v2, единый validator и файловые адаптеры | golden v1, v2 fixtures, roundtrip |
| GeometrySession ведёт отдельную историю от редактора | prepare без принятия результата; GeometryDocumentCommand в общей CommandHistory | смешанная история грань → примитив → Undo/Redo |
| Viewport и picking работают с примитивами Mesh | Derived TopologyBridge и EntityRef с occurrencePath/renderRevision | реальные браузерные клики по грани, ребру, вершине и отверстию |
| v1 parentId — метаданные, а v2 использует иерархические transform | Миграция всех старых примитивов в корневое определение; legacyParentId сохраняется отдельно | ребёнок не перемещается; Euler, материал и пользовательские поля сохраняются |
| Композиция TRS может содержать shear | Полная affine матрица контекста и контроль обусловленности | сравнение с Three.Matrix4, операция через вложенный компонент и Undo |
| Общая геометрия может быть изменена через незаблокированный экземпляр при другом заблокированном | Изменение общего определения запрещено, если хотя бы одно его вхождение заблокировано | unit и браузерная регрессия |
| Устаревший ответ может попасть в новый документ | Session cancellation и проверка revision перед history commit | replace/Undo/другая команда во время pending операции |
| Сохранение удаляет сведения о retired IDs | Persisted provenance и проверяемые tombstone references; ID не переиспользуются | сохранение/открытие и восстановление Undo |

Указанные разрывы устранены в предлагаемом S4. Блокирующий критерий выпуска Windows остаётся открытым: Cargo недоступен, нативная сборка не состоялась. Браузерный download по-прежнему не считается подтверждённой записью и не сбрасывает dirty-state.

## Сохранённые границы

- format: "forma", расширение .v3d, @forma/*, app identity и Windows registry/path compatibility не переименованы.
- Старые v1-файлы открываются и сохраняются как v1 до явного преобразования. Новые проекты создаются как v2.
- Старые сферы/цилиндры не фасетируются автоматически. PrimitiveAdapter используется только для их отображения.
- S3 не заменён алгоритмами Three.js. Подготовка операций продолжает использовать GeometryModel, GeometryDelta, GeometrySession и GeometryPolicy.
- Новый UI рисования, Push/Pull, boolean, экспорт, OpenCascade.js и реальный Worker не входят в S4.
