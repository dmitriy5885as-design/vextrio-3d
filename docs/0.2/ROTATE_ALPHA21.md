# Alpha.21 — вращение топологии

## Использование

1. В документе v2 выберите вершину, ребро или грань. Геометрические элементы должны принадлежать одному определению и активному пути экземпляра.
2. Нажмите **Q** или выберите инструмент «Вращение».
3. Задайте центр вращения в локальных координатах активного контекста, ось X/Y/Z и угол в градусах. Кнопка «Центр из выбранной вершины» подставляет локальную позицию опорной вершины.
4. Просмотрите результат в сцене. Нажмите «Повернуть» или Enter, чтобы записать одну команду. Esc завершает инструмент и убирает preview.

Рёбра и грани разворачиваются в связанные вершины через существующий `moveSelection`; модель не извлекается из Three.js. Перед фиксацией backend строит обратимый GeometryDelta, применяет геометрические ограничения и проверяет документ. Ошибка оставляет документ и историю без изменений.

## Проверяемые данные

Браузерный fixture содержит одно настоящее топологическое ребро:

```text
вершины: [0, 0, 0], [4, 0, 0]
ребро: первая вершина → вторая
выбор: вторая вершина (или середина ребра)
центр: [0, 0, 0] · ось: Z · угол: 90°
```

Ожидаемая координата выбранной вершины — `[0, 4, 0]` (с численной погрешностью менее `1e-7`). ID обеих вершин и ребра остаются прежними. Тесты проверяют выбор через viewport, preview, сохранение `.v3d`, Undo/Redo и отклонение угла `NaN` без записи команды.

## Ограничения Alpha.21

- Числовое вращение вокруг одной из локальных осей X/Y/Z; произвольная ось не вводится.
- Угол ограничен диапазоном ±36000°.
- Все выбранные элементы должны находиться в одном геометрическом контексте; редактирование заблокированного контекста отклоняется.
- Если получившаяся поверхность/оболочка нарушает геометрические ограничения, команда отклоняется целиком.
- Вращение-копия, интерактивный транспортир и массивы вокруг оси не входят в этот блок.
- Windows-native сборка и installer требуют отдельной CI-проверки PR.
