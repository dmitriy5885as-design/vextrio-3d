# Alpha.22 — масштабирование топологии

## Использование

1. Выберите вершину, ребро или грань документа v2 и нажмите **S**.
2. Задайте множители X/Y/Z. `1` оставляет размер вдоль оси, `2` удваивает, `0,5` уменьшает вдвое.
3. Введите центр в локальных координатах активного контекста либо выберите опорную вершину и нажмите «Центр из выбранной вершины».
4. Просмотрите preview и нажмите «Масштабировать» или Enter. Esc отменяет операцию.

Выбранное ребро раскрывается в обе конечные вершины, грань — во все вершины её контуров. Все изменения применяются атомарно через GeometrySession и общую историю редактора. Кандидат проходит существующие проверки Move; если трансформация даёт недопустимые контакты или вырожденную модель, исходный документ и история остаются прежними.

## Проверяемые данные

Для ребра с концами `[0, 0, 0]` и `[4, 0, 0]`, при центре `[0, 0, 0]` и коэффициентах `[2, 1, 1]`, новый конец равен `[8, 0, 0]`. ID вершин и ребра сохраняются.

Для прямоугольной грани `4 × 3 м` в плоскости XZ те же коэффициенты дают `8 × 3 м`, площадь `24 м²`; четыре вершины, четыре ребра и ID грани остаются теми же.

## Ограничения Alpha.22

- Коэффициенты независимы по локальным осям X/Y/Z и должны находиться в диапазоне `0,000001…1000000`.
- Ноль и отрицательные числа запрещены. Отражение будет отдельным инструментом.
- Масштабирование действует только на выделенные топологические вершины в одном геометрическом контексте. Частичный выбор грани может быть отклонён Move-проверками, если нарушит соседние грани.
- Пока нет viewport-рукояток, масштабирования-копии, масштабирования по рулетке и отражения.
