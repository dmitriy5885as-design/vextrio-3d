# Покрытие основных функций SketchUp

Приоритет пользователя: сначала расширить набор работающих основных инструментов, затем шлифовать редкие частные конфигурации. Каждый новый инструмент сразу должен изменять настоящую геометрию, поддерживать отмену, историю, сохранение и проверяемый UI-сценарий.

Ориентир набора: [официальная карточка инструментов SketchUp 2026 для Windows](https://download.sketchup.com/QRC2026/HC-QRC2026-en-SU-windows.pdf), [рисование форм](https://help.sketchup.com/en/sketchup/drawing-basic-shapes), [ластик](https://help.sketchup.com/en/sketchup/erasing-and-undoing). Статусы ниже относятся к VEXTRIO, а не к наличию названия кнопки. Полный паритет пока не достигнут.

## Очерёдность расширения

1. **Текущий блок:** многоугольник, свободное рисование, базовый ластик. Реальные команды и история, без неработающих пунктов интерфейса.
2. **Измерения и основы точного построения:** рулетка, направляющие, транспортир, пользовательские оси; поворотный прямоугольник и дополнительные дуги.
3. **Преобразования:** вращение и масштаб выбранной топологии, отражение, копии и массивы.
4. **Объёмные инструменты:** Follow Me и общий набор операций над телами.
5. **Оформление модели:** нанесение материалов/текстур, размеры, подписи и 3D-текст.
6. **Организация/показ:** теги, сцены, сечения, стили, скрытая/смягчённая геометрия.
7. **Затем систематическая доводка:** сложные стыки и редкие случаи, большие сцены, установленная Windows-версия без сети, обменные рабочие процессы.

Проверки целостности и регрессионные тесты выполняются при добавлении каждого инструмента. Их нельзя откладывать до конца набора: функция считается реализованной только при работающем пользовательском сценарии. Статусы обновляются по фактической реализации.
