# Аудит FORMA 0.1

Аудит кода базы, указанной в [README](README.md), 24 октября 2026. P1 — блокирует надёжное редактирование/сохранение; P2 — существенная архитектурная или эксплуатационная проблема; P3 — улучшение. Это приоритет исправления, не заявление об уязвимости.

## Проверенный исходный уровень

`pnpm test`: 18/18. `pnpm check:deps`: циклов в охватываемых проверкой импортах нет. `pnpm build`: TypeScript и Vite успешны; выходные JS chunks около 319 и 481 kB до gzip. Повторно выполнены 4/4 Playwright-сценария с Chromium/software WebGL. Нагрузочных испытаний и подтверждённой сборки Windows нет. Отсутствие cargo/rustc в PATH подтверждено; ранее `desktop:build` останавливался на `cargo metadata`.

Сохранить: сериализуемый документ отдельно от сцены, примитивы, UUID, команды/Undo, проверку входного файла, GPU dispose, обновление Mesh по ID, render-on-demand, камеры, браузерные файлы и общую кодовую базу Desktop. Эти части полезны, хотя требуют расширения.

## Воспроизведения

Три временных диагностических Vitest-проверки выполнены, затем удалены: они фиксировали нежелательное текущее поведение, не должны закреплять его как норму в постоянном suite.

1. `replace(emptyProject()); add('cube'); patch(id,{transform:{position:[0,1,0],rotation:[0,0,0],scale:[0,1,1]}})` — store принимает нулевой scale, `serializeProject` бросает ошибку. Подтверждён дефект границы команд; получение такого scale конкретным жестом gizmo отдельно не проверялось.
2. `patch(id,{locked:true}); patch(id,{locked:true,name:'changed while locked'})` — имя изменяется. Подтверждён обход прикладной блокировки через API; это не исследование безопасности аккаунтов.
3. v1 с parent X=10, child X=1 и parentId проходит parse/roundtrip. Отсутствие наследования transform подтверждено чтением viewport, не отдельной численной E2E-проверкой.

Для S1 первые два воспроизведения превратить в постоянные regression tests с обратным ожиданием: кандидат отвергнут, состояние/история не изменились. Для hierarchy добавить эталон фактического отображения 0.1 и golden миграцию.

## Производительность: что известно и что ещё измерить

Из кода установлены O(N) клоны/сериализации на правку и linear raycast/sync; O(N³) — верхняя оценка валидации цепочки parentId, не измеренное время. Не делались выводы об FPS, памяти или максимальном размере модели по одной тестовой сцене.

Сохранить затраты хорошего дизайна 0.1: сцена не пересоздаётся на каждое изменение React, requestAnimationFrame запрашивается по событию, геометрия пересоздаётся при смене описания, dispose присутствует. Расширение должно сохранять эти свойства.

Обязательные будущие измерения: 100/1000/10000 объектов legacy; 1k/10k/50k рёбер; худшие пересечения; 100 последовательных операций; repeated mount/open/close; heap/GPU lifetime; Node+browser+WebView2 на указанном CPU/GPU. Производственные лимиты выбирать после отчёта, а не из произвольной константы.

## Вывод о переписывании

Полная замена редактора не обоснована. Нужны новые топологические типы и алгоритмы, а также последовательная замена узких контрактов geometry/tools/snapping. CommandHistory, rendering lifecycle и FileService расширяются по совместимому мосту. Изменения UI обслуживают рисование и точность. Оболочка Tauri остаётся, её непроверенные функции должны получить собственный release gate.
