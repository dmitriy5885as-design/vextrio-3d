# Alpha.23 — отражение топологии

## Использование

1. Выберите вершину, ребро или грань документа v2 и нажмите **S**.
2. В панели преобразований выберите **Отражение**.
3. Задайте ось нормали плоскости (**X**, **Y** или **Z**) и координату плоскости в единицах проекта. Ось и координата относятся к локальным координатам активного геометрического контекста.
4. Проверьте preview и подтвердите кнопкой **Отразить · Enter**. **Esc** завершает операцию.

В корневом контексте плоскость X=0 отражает точку `[4, 2, 3]` в `[-4, 2, 3]`. Ненормальная (не единичная) нормаль ядром нормализуется, а координата плоскости задаётся числовым вводом с поддержкой единиц проекта.

## Топология и целостность

- Работа идёт с GeometryModel и стабильными ID; Three.js используется только для preview и отображения.
- При отражении грани меняется направление её coedge циклов и пересчитывается frame плоскости. Материалы front/back следуют за отражённой поверхностью.
- Для целого замкнутого тела сохраняются ID, связи и классификация `closed-shell`.
- Preview строится через GeometrySession и не меняет исходный документ. Commit проходит общие проверки Move, атомарно записывается в историю редактора и сериализуется в `.v3d`.
- Undo/Redo восстанавливает исходные и отражённые координаты, ориентацию и ID.
- Если отражение задевает грань лишь частично, операция отклоняется. Сначала выберите все её граничные вершины; соседние грани, задетые только частью boundary, тоже блокируют преобразование. Это предотвращает случайное изменение формы и некорректную ориентацию поверхности.

## Проверяемые данные

- Wire: вершина `[2, 0, 0]` отражается относительно X=0 в `[-2, 0, 0]`; ID ребра и вершин не меняются.
- Лист 2 × 2 м в плоскости XZ отражается относительно Y=0 без изменения площади; frame нормали получает корректную противоположную ориентацию, стороны материала сохраняются.
- Тетраэдр отражается как целая замкнутая оболочка: количество и ID сущностей сохраняются, `classifyBody` возвращает `closed-shell`.
- Настоящий браузерный сценарий выбирает грань во viewport, запускает S → Отражение, подтверждает результат, сохраняет `.v3d`, проверяет координаты и Undo/Redo.

## Ограничения Alpha.23

- Пока доступны только ортогональные плоскости X/Y/Z активного локального контекста с координатным смещением.
- Не реализованы интерактивный манипулятор плоскости, отражение-копия и отражение произвольно выделенного фрагмента грани.
- Выбор должен включать целые грани одного геометрического контекста; блокировки контекста сохраняются.
- Полный паритет со SketchUp не заявляется.
