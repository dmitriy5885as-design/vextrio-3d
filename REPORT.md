# Результат реализации FORMA · 24 октября 2026

Создан работающий браузерный фундамент FORMA 0.1 Foundation в фирменном стиле пользователя. Это версия в разработке: подтверждение готовности Windows остаётся открытым.

## Проверено

| Проверка | Результат |
|---|---|
| `pnpm build` | Успешно: строгий TypeScript, production-сборка Vite |
| `pnpm test` | 18 тестов прошли |
| `pnpm check:deps` | Циклических зависимостей нет |
| Playwright | 4 сценария прошли, Chromium с программным WebGL |
| `pnpm desktop:build` | Остановлен: `cargo metadata` — program not found |

Браузерные сценарии: перетаскивание манипулятора с одной записью Undo; создание куба, X=4,25, скачивание и открытие .v3d; выбор мышью, дублирование и история, переключение камер и тем при 1366×768 и 1920×1080; отмена нового проекта и открытие повреждённого файла с сохранением текущих данных. Проверки рабочих сценариев не зафиксировали ошибок JavaScript.

Модульные тесты проверяют roundtrip документа с камерой/материалами/единицами, уникальность ID, некорректные JSON и версии, повторяющиеся ID, NaN, циклы/отсутствующих родителей, недопустимые камеру и масштаб, все примитивы, смешанную историю, ветвление после Undo, независимость копий, блокировку, открытие, привязки и сохранение навигационной камеры при Undo/Redo.

## Архитектурные решения

Документ отделён от Three.js. Пакеты соответствуют подсистемам ТЗ. Команды используют ограниченную историю снимков; манипулятор фиксируется при отпускании. Сцена обновляет существующие Mesh по ID и рисуется по запросу; GPU-ресурсы освобождаются. Сетка разбита на короткие сегменты, чтобы избежать обнаруженных артефактов отсечения длинных линий в программном WebGL. Формат имеет версию и строгую входную проверку. Открытие сначала валидирует файл, затем заменяет проект. Геометрический адаптер реализует примитивы; план Worker/OpenCascade и устойчивых ID описан отдельно.

## Оставшиеся ограничения

Нативные команды Tauri и установщик NSIS требуют сборки и проверки в Rust/MSVC/WebView2; Windows EXE не выпущен. Браузерное сохранение — скачивание файла: приложение подтверждает передачу браузеру, а не физическую запись на диск. Нет B-Rep, Push/Pull, boolean, линий, групп, мультивыделения, внешних форматов, автосохранения и восстановления после аварии. Родительские ссылки валидируются и сохраняются, но иерархические трансформации не применяются. Настройки действуют в сеансе; полная локализация ещё не завершена. Производительность на реальном GPU и больших сценах не измерялась.

Задачи 0.2: контуры и линии, точные размеры, привязки к сущностям, Worker-контракт на массивах, миграции формата, оптимизация истории и React-подписок, автосохранение и настройки. Юридическая проверка FORMA и знака остаётся задачей до публичного запуска.
