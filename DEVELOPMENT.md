# Разработка

1. Node 22 LTS, pnpm 11; установить зависимости из lockfile.
2. `pnpm build`, `pnpm test`, `pnpm check:deps`, `pnpm test:e2e` перед изменением релиза.
3. Strict TypeScript: не обходить типы через any и не отключать тесты.
4. Не хранить Mesh и WebGL-ресурсы в документе. Изменения объектов — только через команды.
5. Новый пакет должен иметь реализацию и явные зависимости без циклов.
6. Каждому GPU-ресурсу нужен dispose. Сцену не пересоздавать из-за обновления React.
7. Новая версия формата требует валидатора, миграции и roundtrip-теста.
8. Нереализованные операции отключать с объяснением.

В среде с запретом localhost браузерные тесты требуют разрешённого локального сетевого доступа. Chromium устанавливается через `pnpm exec playwright install chromium`. E2E сохраняет снимок в `test-results/forma-editor.png`.

Критический сценарий вручную: новый проект → куб → X = 4,25 → сохранить → новый проект → открыть файл → выбрать куб → проверить X = 4,25. Затем проверить манипулятор, Undo/Redo, блокировку, отмену открытия и повреждённый JSON. Повторить при 1366×768 и 1920×1080, в обеих темах.

Лицензии установленных библиотек хранятся с пакетами в node_modules. Перед распространением собрать third-party notices и проверить транзитивные лицензии. Визуальный знак — собственный SVG по направлению пользователя, шрифт берётся из системного стека; Inter/Manrope отдельно не поставляются.
