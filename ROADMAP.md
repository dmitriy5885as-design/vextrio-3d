# План версий

Все основные инструменты, сохранение и экспорт остаются бесплатными; регистрация не обязательна, Windows должна работать offline. Новые [продуктовые принципы](PRODUCT_STRATEGY.md) заменяют прежнее направление Pro/Edu. Архитектура 0.2 подготовлена и ожидает утверждения.

| Версия | Название          | Основная область                           |
| ------ | ----------------- | ------------------------------------------ |
| 0.1    | Foundation        | Документ, сцена, примитивы, история, файлы |
| 0.2    | Sketch            | Линии, контуры, точные размеры             |
| 0.3    | Solid             | Объёмные операции, Push/Pull               |
| 0.4    | Structure         | Группы и компоненты                        |
| 0.5    | Exchange          | Импорт и экспорт                           |
| 0.6    | Precision         | Геометрия и привязки                       |
| 0.7    | Materials         | Материалы и оформление                     |
| 0.8    | Workflow          | Продуктивность                             |
| 0.9    | Release Candidate | Оптимизация и проверка                     |
| 1.0    | Genesis           | Первый стабильный релиз                    |

## Перед подтверждением 0.1.0

- Собрать и испытать Windows NSIS в среде Rust/MSVC/WebView2.
- Проверить нативные сохранение, отказ доступа, отмену диалога и закрытие окна с изменениями.
- Измерить производительность на больших сценах и реальных GPU; провести ручную проверку доступности.

## 0.2 Sketch

Подробные требования: [ТЗ](docs/0.2/SPECIFICATION.md). Порядок малых этапов и критерии: [план](docs/0.2/IMPLEMENTATION_PLAN.md). Главный приоритет — topology и реальные линии/грани; настройки и дополнительная локализация не должны задерживать геометрическое ядро.

- Worker-ready контракт геометрии на типизированных массивах и capabilities.
- Инструменты линии и замкнутого контура на рабочей плоскости, отмена незавершённого ввода.
- Числовой ввод длины, размерные аннотации, привязки к точкам/рёбрам/осям.
- Миграция формата и тесты совместимости v1 → v2.
- Сжатие истории, объединение непрерывных слайдеров, отдельные UI/document stores и селекторы.
- Автосохранение и восстановление, сохранение настроек, полноценный английский словарь.
- Проверка доступности имени и знака до публичного запуска.
