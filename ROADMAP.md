# План версий

Текущая версия — **0.2.0-alpha.1**: [состав, проверки и ограничения](docs/0.2/ALPHA_02.md). Реализованы Sketch S1–S6, ограниченное выдавливание, группы/экземпляры, экспорт OBJ/STL, новый CAD-навигатор, цвет граней и локальное восстановление. Это альфа, не полный аналог SketchUp.

Следующие приоритеты: production Worker и большие сцены; надёжные сквозные проёмы/CSG и изменение формы; круг/дуга, конверсия примитивов, внешний импорт. Отдельная Windows-приёмка установки и offline работы остаётся обязательной.

Первоначальный план областей развития ниже сохраняется как ориентир; частичные возможности могли появиться раньше указанного этапа.

Все основные инструменты, сохранение и экспорт остаются бесплатными; регистрация не обязательна, Windows должна работать offline. Новые [продуктовые принципы](PRODUCT_STRATEGY.md) заменяют прежнее направление Pro/Edu. Архитектура 0.2 утверждена. S1–S6 реализованы; native сборка проверяется в CI, ручной Windows release gate открыт.
